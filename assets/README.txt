LUXMI BRICK FIELD — Logo Package
=================================
Prayagraj, Uttar Pradesh

FILES INCLUDED:
---------------
1. luxmi_logo_primary.svg         — Main logo (light backgrounds)
                                    Use on: website hero, letterhead, hoardings, flex boards

2. luxmi_logo_dark.svg            — Dark version (dark backgrounds)
                                    Use on: dark navbars, social media covers, banners

3. luxmi_logo_horizontal.svg      — Horizontal lockup (light)
                                    Use on: website navbar, business cards, invoices, email footer

4. luxmi_logo_horizontal_dark.svg — Horizontal lockup (dark)
                                    Use on: dark navbar, dark business card, merchandise

5. luxmi_icon_square.svg          — Square icon mark (512x512)
                                    Use on: favicon, WhatsApp DP, Google Maps listing, app icon

BRAND COLOURS:
--------------
Deep Brown   #1C0800   — Primary background / icon
Brick Red    #B84A1A   — Main brick colour
Brick Orange #D4622A   — Alternate brick rows
Gold         #C08030   — Accent lines, bars
Cream        #F9F6F2   — Light background
Text Dark    #3A1800   — Body text

HOW TO USE IN NEXT.JS:
-----------------------
1. Copy luxmi_logo_horizontal.svg to /public/logo.svg
2. In Navbar.tsx:
   import Image from 'next/image'
   <Image src="/logo.svg" width={260} height={55} alt="Luxmi Brick Field" />

HOW TO CONVERT TO PNG (free tools):
-------------------------------------
- https://cloudconvert.com/svg-to-png
- https://svgtopng.com
- Recommended export sizes:
  Primary logo    : 1200 x 640 px
  Horizontal logo : 1040 x 220 px
  Square icon     : 512 x 512 px (also use as favicon)

HOW TO CREATE FAVICON (.ico):
------------------------------
1. Export luxmi_icon_square.svg as 512x512 PNG
2. Go to https://favicon.io/favicon-converter/
3. Upload PNG → Download .ico
4. Place in /public/favicon.ico
